# Velvet Landing Page Project

Build a single-page fragrance landing page called VELVET, a flanker product under the brand Sarkar Perfume (reference site: sarkar.store). Match Sarkar's existing visual identity: dark, minimal, luxury, bold typography, black/charcoal background with gold or cream accents, unisex positioning.

Important: do not redesign the packaging. The bottle must use the same existing Sarkar packaging design and chess-piece motif used across Throne, Regal, Noble, and Orion — same bottle shape, cap, label style, and chess styling. Leave a placeholder image area for this bottle shot; do not generate a new bottle design.

Sections needed, in order:

Hero — Full-width dark background. Large bold headline "VELVET". Tagline below in tracked-out caps: "WARM. QUIET. UNSHAKEN." Small CTA button "EXPLORE PARFUM".

Notes section — Three fragrance notes displayed like a badge/label row: "VANILLA · AMBER · TONKA". One short line under it: "Power doesn't shout. It settles into a room and stays."

Product image area — Centered placeholder for the existing Sarkar chess-themed perfume bottle, captioned "100ml · Eau de Parfum". Keep the packaging exactly as-is, only the label/name changes to VELVET.

Story/brand block — Short paragraph (2-3 lines max) about Velvet as part of the Sarkar collection, same commanding tone as Throne/Regal/Noble/Orion.

Pricing / CTA — Price ₹1,799, "Add to Cart" button, small line "Incl. of all taxes".

Footer — Minimal: Sarkar logo/name, links (Shop All, Know Sarkar, Contact), social icons row, copyright line.

Style requirements: mobile-first, fast-loading, no unnecessary animations, generous spacing, serif or bold sans-serif display font for headlines, all-caps tracking for taglines like the reference site. Keep the whole page lightweight — optimize images, no large background videos.
